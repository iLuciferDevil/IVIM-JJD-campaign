Data definitions and limitations

Blended CPR = (Meta spend + Google spend) / (Meta registration conversion events + Google registration conversion events). This is a platform-attributed conversion-event metric, not deduplicated unique registrations. A cross-platform-attributed conversion may be counted twice. Use the same registration event in each platform. Other conversion types must be excluded. CSV input is for aggregated campaign-level exports, not patient-level or personally identifiable data.

Supported common CSV columns: Meta: Reporting starts, Campaign name, Amount spent (USD), Link clicks or Clicks (all), and a registration event column. Google: Day, Campaign, Cost, Clicks and a registration conversion action column. If the registration event is not automatically recognized, the import asks you for its exact column name. For Google, segment the report by the intended registration conversion action, rather than importing total All conv.

90-day LTV to CAC will be added when verified registration, appointment and revenue sources become available. This POC uses browser-local storage and is not a shared source of truth; production reporting will need a controlled data pipeline and access protection.
